# Site SoluTi Tech Store

Site institucional estático da SoluTi Tech Store, assistência técnica em Araranguá/SC.

## Visualizar e editar

1. Abra a pasta `site-soluti` no Visual Studio Code.
2. Clique duas vezes em `index.html` para abrir o site no navegador.
3. Edite o conteúdo em `index.html`, o visual em `style.css` e o menu em `script.js`.
4. As imagens e a logo ficam na pasta `images`.

Não é necessário instalar Node.js, executar `npm install` ou usar servidor local.

## Publicar no GitHub Pages

Envie estes arquivos para um repositório do GitHub e, nas configurações do repositório, ative o GitHub Pages usando a branch `main` e a pasta raiz (`/root`).
